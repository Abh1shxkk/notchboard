## Name
Notchboard: New Tab Dashboard, Tab Manager & Focus Timer

## Summary (max 132 characters)
One-screen new tab dashboard with a tool dock, tab manager, focus timer, to-dos and history stats. Private: local data only.

## Category
Productivity → Workflow & Planning

## Language
English

## Description
Notchboard turns every new tab into a one-screen command center built from the sites you actually use. No accounts, no setup, no data leaving your browser.

WHAT YOU GET
• A macOS-style dock of your tools. If a tool is already open, clicking it jumps to that tab instead of opening a duplicate.
• Daily brief: a small notch at the top that asks one question at a time: close duplicate tabs, close tabs you haven't touched in days, save a crowded window, or start a focus block.
• Search everything: your tools, open tabs, 30 days of history and quick actions. Press Ctrl+K for the command palette, or type "todo: …" to add a task.
• Focus timer (25 / 50 / 90 / 5 minutes) that keeps running after you close the tab and notifies you when it ends.
• Time card with day progress and UTC, London and New York clocks.
• Tabs: see everything that's open, spot duplicates and close them, or restore recently closed tabs.
• Most used sites, a 7-day activity heatmap and today's browsing stats.
• To-do list, scratchpad and workspaces (save a window of tabs and reopen it later in one click).
• Light and dark themes, frosted-glass cards and subtle micro-interactions.

PRIVATE BY DESIGN
Everything is read from Chrome on your own device. The extension makes no network requests, has no analytics and stores nothing outside your browser.

KEYBOARD
/ focus search · Ctrl+K command palette · Alt+1–9 open dock tools · B open the daily brief · Esc close

## Single purpose (Privacy practices tab)
Replaces the new tab page with a personal productivity dashboard built from the user's own tabs, history and tools.

## Permission justifications (Privacy practices tab)
- topSites: Suggests the user's most visited sites as dock tools on first run.
- history: Shows most used sites, today's page count and a weekly activity heatmap, and lets the user search their history from the new tab page.
- tabs: Lists open tabs, detects duplicates, and switches to an already-open tool instead of opening a duplicate tab.
- sessions: Lists recently closed tabs so the user can restore them.
- storage: Saves the user's dock tools, to-dos, notes, workspaces and settings locally.
- favicon: Displays site icons from Chrome's local favicon cache.
- search: Sends searches typed on the new tab page to the user's default search engine.
- alarms: Ends a focus timer the user started, even when the new tab page is closed.
- notifications: Tells the user when their focus timer has finished.

## Data usage disclosures
The extension reads web history and tab URLs **only on the device** and never transmits them. If the form asks which data types are handled, select **Web history**, then certify that the data is **not sold**, **not transferred to third parties**, **not used for unrelated purposes**, and **not used for creditworthiness or lending**. Check the current wording of the Chrome Web Store user-data FAQ when you fill this in, since the form changes from time to time.
